## 사용자 요구사항 원문 요약 (변경 시 기준)

- 영어 단어 시험. 두 자녀가 따로 사용. 부모 둘 중 한 명 또는 둘 다 관리(결과 확인 등).
- 일주일에 두 번 시험. 주 100개 정도를 50개씩 나눠 시험. 시험 문항 수는 정하지 않음.
- **시험은 등록일 + 1일부터**, **최소 50개** 이상이어야 시험 가능.
- 단어 스펠링 또는 뜻을 입력, 자동 채점. 결과 저장·조회. 틀린 단어 재시험.
- 단어는 미리 등록. 사진 촬영 또는 직접 입력. 자녀도 등록 가능.
- 자녀도 자기 아이디/비밀번호로 로그인.
- 발음 듣기.
- 사용 가능 인프라: Vercel, Supabase, GitHub. 사진 인식은 무료인 Gemini 선호.
- 결정은 권장안으로 진행하고, 사람 손이 필요한 일만 마지막에 전달.

## 주요 결정과 이유

| 결정 | 이유 / 대안 |
| --- | --- |
| BFF(서버만 DB 접근) + RLS 전면 차단 | 정답 비노출·규칙 우회 방지가 핵심. 테이블별 RLS 정책보다 단순하고 실수 여지 적음 |
| 출제·제출 규칙을 plpgsql 함수로 | 동시성(두 기기 동시 시작/제출)과 원자성. 앱 코드는 채점(순수 함수)만 |
| 단어장(세트) 없이 등록일 단위 | "50개씩 등록 → 다음 날 시험" 흐름에 맞춤. 출제 대상은 자동(미출제 전부) |
| 1회 출제 상한 300(오래된 순) | 상한 초과 시 영원히 시험 불가가 되는 문제 방지 |
| 자녀 = learners + 선택적 Auth 계정 | 부모 기기 공유와 아이 단독 로그인 둘 다 지원. 가상 이메일 `.invalid`로 메일 발송 없음 |
| 부모 모드 = 가족 공용 PIN + 서명 쿠키 30분 | 부모 계정으로 로그인된 기기를 아이가 써도 관리 기능 보호 |
| 뜻 채점: 후보 중 하나면 정답, 여러 개 쓰면 전부 맞아야 | 아이가 뜻을 나열해 찍는 것 방지. 유의어·활용형은 부모 정정으로 처리 |
| 사진 인식은 AI(Gemini 우선), 결과는 항상 사람이 확인 | 교재가 사전형(예문·파생어 혼재, 2단)이라 줄 단위 OCR로는 불가 |
| 철자 발음은 문항 id로 서버 합성 | 응시 중 정답 철자 비노출 |

## 알려진 한계 / 후속 후보

- **사진 인식 정확도**: 교재 형식별 프롬프트 튜닝 여지. 문제 사진이 오면 `src/lib/server/ocr/prompt.ts` 예시를 보강.
- **Gemini 무료 등급**: 입력이 Google 개선에 쓰일 수 있음. 민감 사진 주의. 한도 초과 시 429.
- **TTS**: 운영은 Google Cloud TTS. 키가 없을 때만 비공식 Translate TTS(일반 공개 시 경로 제거 예정). 기기 음성은 영어 보이스가 있으면 우선 사용.
- **일반 공개 검토(2026-10-18)**: 광고 붙이면 Vercel Pro 필수(Hobby는 비상업). 무료 공개라도 개인정보 처리방침·14세 미만 법정대리인 동의, 회원 탈퇴(데이터 삭제), 사진 인식·TTS 사용자별 호출 한도, 커스텀 SMTP, 가입 허용이 선행돼야 함. 무료 구성 수용 규모 추정 50~100가족.
- **자녀 프로필 간 전환**: 부모 계정 기기에서는 형제 프로필로 자유롭게 바꿀 수 있음(자녀 계정 로그인은 고정).
- **HEIC**: iOS Safari는 자동 변환, 데스크톱 Chrome에서 HEIC 파일은 열 수 없음(안내 메시지 표시).
- **이메일 인증 링크**: PKCE라 가입한 브라우저에서 열어야 함.
- **키보드 전환**: 웹은 키보드 언어를 지정할 수 없어 `inputMode=email` 힌트에 의존(iOS 영문 ASCII 키보드, 안드로이드는 키보드 앱에 따라 다름).
- **기존 단어 순서 보정 한계**: 보정 전 등록 후 수정된 단어는 해당 날짜 묶음 끝으로 갔을 수 있음.
- 후보 기능: 시험 문항 등록 순서 출제 옵션, 단어를 다른 자녀에게 복사, 주간 리포트(부모 알림), 시험 시간 제한, 다크 모드, 오답 연습 결과 저장(연습 통계).
